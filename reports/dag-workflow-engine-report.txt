DESCRIPTION
----------------------------------------------------------------------
DAG-based workflow orchestration for ML pipelines. YAML task dependencies, topological execution with parallelism, retry with backoff, state persistence.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - networkx
  - pydantic
  - pyyaml
  - click
  - rich
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * YAML DAG configuration
  * Topological execution
  * Built-in ML tasks
  * Retry with backoff
  * State persistence
  * Rich terminal UI

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  YAML pipeline

  Example:
    dagflow run --pipeline ml_pipeline.yml

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Pipeline execution

  Example:
    Complete: 6/6 tasks passed (12.3s, 2 parallel generations)
